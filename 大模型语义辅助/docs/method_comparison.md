# 方法对比表

本表用于说明“只使用大模型语义判断”和“本项目三维功能理解方法”的区别。大模型在本任务中作为语义辅助或对照基线使用，不替代三维点级可供性预测。

| 方法 | 输入 | 输出 | 可直接评价的指标 | 当前结果/状态 | 适用性结论 |
|---|---|---|---|---|---|
| 豆包/通用多模态大模型 | RGB 图像 + 文本提示 | 物体类别、可能功能、文本描述 | 语义类别准确率、功能类别召回/准确率 | 需按同一测试集调用 API 后统计 | 适合做语义先验，不适合直接输出三维点级功能区域 |
| 本地 Qwen3.5-2B 语义辅助（封闭类别） | RGB 图像 + 候选类别表 + 文本提示 | 物体类别、候选 affordance、文本描述 | 语义类别准确率、文本级 affordance 覆盖率 | 206 / 226 = 91.15% | 可离线复现，适合替代豆包做本地语义基线；但不能输出 mask 和三维功能区域 |
| YOLO-seg 目标识别 | RGB 图像 | 目标类别 + 2D mask | mask IoU >= 0.50 且类别正确 | 225 / 226 = 99.56% | 适合目标识别，不处理三维可供性 |
| GEAL/affordance_model 功能理解 | 点云 + affordance 查询 | 点级可供性响应 | 距离容忍 aIoU，d=0.10，aIoU 阈值=0.13 | 857 / 1000 = 85.70% | 适合三维空间级功能区域定位 |
| 本项目完整方法 | RGB → 目标识别 → 三维/点云 → 功能理解 | 目标类别、mask、三维可供性区域 | 目标识别准确率 × 功能理解准确率 | 85.3208% | 覆盖目标识别和可执行空间功能理解，是最终采用方案 |

## 优势表述口径

豆包、Qwen 等大模型的优势是语义常识强，可以判断“水壶通常可抓取、可倾倒、可容纳”。但本项目指标要求的是机器人可执行层面的结果，需要目标 mask 和三维点云上的可供性区域。通用大模型本身不直接输出点云点级标签，因此不能直接计算本项目的 3D aIoU。

可写成：

> 大模型用于生成物体类别和候选可供性的语义先验，本项目方法进一步结合目标分割和三维点云功能预测，将语义级功能判断转化为可执行的空间级功能区域。相比纯大模型语义判断，本方法不仅能够判断“有什么功能”，还能够定位“功能区域在哪里”，并可通过 mask IoU 和三维 aIoU 进行定量评价。

## 提升量计算方式

如果后续需要给出“相比豆包提升多少”，建议按同一批 RGB 图像跑豆包或 Qwen 语义基线，再用下式统计。本次已完成本地 Qwen 封闭类别语义基线，语义类别准确率为 91.15%；本项目目标识别模型为 99.56%，绝对提升约 8.41 个百分点。

```text
绝对提升 = 本项目综合准确率 - 大模型基线准确率
相对提升 = (本项目综合准确率 - 大模型基线准确率) / 大模型基线准确率
```

注意：若大模型只输出文本类别和功能描述，不能直接与三维 aIoU 指标比较。需要将其定义为“语义基线”，或者额外接入 2D/3D 区域生成模块后再计算完整指标。
