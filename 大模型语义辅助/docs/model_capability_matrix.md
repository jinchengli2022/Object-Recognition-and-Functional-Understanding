# 大模型能力边界表

| 子任务 | 豆包/Qwen 是否能做 | 输出形式 | 是否可直接计入指标2.3 | 说明 |
|---|---:|---|---:|---|
| RGB 图像中物体语义识别 | 可以 | 文本类别，如 `kettle`、`charger` | 部分可以 | 可统计类别准确率，但不输出 mask |
| 判断物体可能具备哪些可供性 | 可以 | 文本列表，如 `grasp,pour,contain` | 只能作为语义指标 | 能提供功能常识，但不是空间区域 |
| 生成功能描述 | 可以 | 中文/英文自然语言说明 | 不直接计入 | 适合报告解释和人机交互 |
| 目标实例 mask 输出 | 通常不稳定/不直接 | 需要额外检测/分割模型 | 不能单独计入 | 应由 YOLO-seg、SAM 等模型完成 |
| 三维点云重建 | 不能 | 无 | 不能 | 需要 MV-SAM3D 或其他 3D 重建方法 |
| 点云点级 affordance 区域预测 | 不能直接做 | 无或文本描述 | 不能单独计入 | 本项目由 GEAL/affordance_model 完成 |
| 距离容忍 aIoU 计算 | 不能 | 无 | 不能 | 需要点级预测和点级 GT 标签 |
| 候选类别/候选 affordance 先验 | 可以 | 类别和功能候选 | 可作为辅助模块 | 可减少错误查询或生成自然语言说明 |

## 推荐使用方式

大模型不作为最终空间预测模型，而作为辅助模块：

1. 输入 RGB，输出物体类别候选；
2. 根据类别输出候选 affordance；
3. 将候选 affordance 传给点云功能理解模型；
4. 最终由点云模型输出三维功能区域并计算 aIoU。

这种设计能把前沿大模型方法用进系统，同时避免把通用大模型不擅长的三维点级定位任务强行交给它。
